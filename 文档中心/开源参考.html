自动吹奏有违规与封号风险

已实现的自动模式使用普通 SendInput 模拟键鼠。使用系统接口不会自动获得游戏许可，也不能保证免于检测或处罚。实现与本地检查通过不等于游戏官方许可。

默认手动跟谱，不向游戏发出输入；选择自动吹奏将按乐谱发出键鼠事件。本软件未获官方认证，尚未实机校准，不宣称“防封”“过检测”或零风险。

在线曲库与许可来源

POP909：909 首中文流行歌钢琴编配

Music X Lab 官方 POP909 仓库提供歌曲标题、歌手与编号索引，以及按编号存放的真实 MIDI；MELODY 为主旋律，BRIDGE 与 PIANO 提供其他旋律和伴奏。本版本只预置轻量元数据，选曲后按需下载，不复制整个音乐数据集。

仓库 LICENSE标注 MIT、Copyright (c) 2020 Music X Lab；原文完整保存在 POP909-LICENSE。界面采用“POP909 · 仓库标注 MIT”，保留数据集与歌手署名。仓库许可不等于现代歌曲原作、歌词或录音变成公版，不据此统一标记 Public Domain。

本地索引：pop909.json；原始 index.xlsx已核验 909 条。曲目歌手以索引为准，例如《七里香》为刘瑞琦版本；编配与所选平台录音不保证时序或调性一致。查看选谱流程。

Mutopia：免费乐谱与 MIDI

Mutopia 官方首页截至查证日期显示 2124 首作品，提供 PDF、MIDI 与可编辑 LilyPond 格式；曲目以古典、传统和开放许可作品为主。作品目录数量不能理解为 2124 首均有单文件 MIDI、均适合口琴或均能在游戏中演奏。

根据官方许可说明，各曲标记 Public Domain、CC BY 或 CC BY-SA。CC BY 要求署名；CC BY-SA 还要求修改后的分发作品遵循相同许可。本版本下载时保存作品页面、许可与署名，具体使用以所选曲目的条款为准。

QQ 音乐与酷狗：同页优先选谱，录音转录另选

在线曲库默认第一页为 QQ／酷狗，中文 MIDI 第二，备用免费谱最后；歌曲来源默认 QQ音乐，可选择酷狗音乐。使用平台网页接口，非正式合作 API，也不是免费 MIDI 库。歌曲页下方优先提供明确的 POP909 主旋律编配；歌名、歌手和录音版本符合推荐条件时可选用，Live 或待确认版本必须明确选择。谱校验或下载失败不自动改成音频转录；录音使用独立“下载录音 → MIDI”，同页显示下载、组件准备、转录与保存，成功后“立即选用”。主曲库右键可“查找主旋律谱（保留原谱）”，不覆盖旧谱，不二次弹音频设置窗或要求填 URL。查看歌曲与选谱流程。

QQ 下载按软件内官方页的实际账号权限和普通完整音频地址处理；会话失效时提示重新登录，并提供退出登录。外部浏览器会话不会自动同步，“官方歌曲页 ↗”仍仅打开外部详情。酷狗核对权限、歌曲标识、时长和官方完整 MP3 路径，不取片段。受限或无普通地址时同页说明，可换版本或用“已有音频转 MIDI”；不伪造身份或签名，不解密 QMC／MGG／MFLAC／KGM。登录操作与真实账号验证状态另行记录。

QQ 官方客户端下载 · 酷狗官方客户端下载 · QQ 官方用户协议。QQ 协议在版本 1.4 读取超时，未逐条核验；酷狗官方客户端下载入口在版本 1.5 核验，不据此声称免费歌曲全部允许重新分发。

腾讯音乐的官方 QPlay OpenAPI 示例与官方 OpenID 示例属于合作接口，需要应用参数与授权，软件没有集成这些伙伴 API。当前内置登录采用官方网页会话，账号会话由 Windows DPAPI 保护，本软件专属网页资料单独保存；退出只清本软件会话与浏览资料，不能当场清理时下次打开补清。版本 1.7.2 已用真实微信官方网页会话排查旧版识别误拒，当前会话候选条件已修正；实际会话与匿名请求的官方接口对照已经区分出账号状态；带会话返回成功和去标识化资料，不带会话返回账号错误。官网资料接口也有带／不带会话的区别，说明旧数字账号要求误拒了当前格式；读取用户现有微信会话后，产品默认 ValidateAccount 真实网络验证为 True、IsUsable=True、FailureKind 为空；网页相同 User-Agent 的诊断传输也通过。未代用户扫码、未持久化正式账号会话、未退出或清理资料；真实 QQ 扫码及会员下载未测试。版本 1.7.1 的 2026 年 10 月 2 日历史记录中，QQ 与酷狗宋祖英《茉莉花》的普通整曲下载→转录→解析均成功，保存于隔离曲目目录，未加入用户曲库或人工听音；这些结果不证明账号或会员权限通过。查看实际数值与边界。

Microsoft WebView2：软件内显示官方登录页面

微软 WebView2 官方介绍说明该控件可在原生应用内显示网页。使用 Microsoft.Web.WebView2 1.0.2903.40 官方 NuGet 包，登录页面由 QQ 音乐官方提供，软件使用专属会话而非读取外部浏览器账号。SDK 约增加 0.9 MiB，复用本机已安装的共享运行时；本机运行时为 154。微软的运行时部署说明区分 SDK 与运行时，后者需在设备上可用；不据本机已有推断所有电脑都有。

版本 1.7.1 已部署 SDK 及加载文件，四个 DLL 的微软 Authenticode 签名检查均为 Valid；此证据不等于真实账号登录成功。包内许可条款要求分发时保留版权、条款及免责声明，不得借微软名称为衍生产品背书；本地保留 WebView2 LICENSE.txt。官方页面渲染、会话和退出流程的最终验证另见软件内登录说明。

Basic Pitch：普通音频转录为 MIDI

Spotify Basic Pitch 官方项目是音频转 MIDI 的自动转录工具，采用 Apache-2.0 许可；官方说明单一乐器录音通常更适合识别。工具许可不改变输入录音的原有授权。

采用 Basic Pitch 0.4.0、ONNX Runtime 1.19.2 与独立 Python 3.10.11，首次转换由窗口自动准备，后续可离线识别，不上传录音。模型的多乐器音高支持概率不区分主唱身份。版本 1.8.1 的连续旋律后处理只在更连贯、具有起音与音高变化证据的音区候选满足严格条件时调整候选，仍可能混入伴奏；至少 40 毫秒且有明确起音证据的短音可保留，证据不足的短段保留为间隙，并在达到提示条件时标出“短音未定”。轨名继续显示“连续旋律估计”“需试听”及“候选需核对”等提示。本轮《奇迹再现》12 秒缓存仍为 54 个音、发音总长约 8.342 秒、短音约 59%，未证明听感改善；Python 38 项算法检查也不是主唱准确度验证。查看当前结果与历史边界。

优先选用现成 MELODY 编配；在线同页取得平台普通音频或选择本机文件时，录音转录是独立操作。已有配对录音可右键重新转录，新增连续旋律版并保留原 MIDI，成功后曲库立即刷新。查看重新转录与比较方法。

版本 1.7.1 的组件修复沿用至当前版本。统一转换入口校验实际组件目录，准备完成需同时具备完成标记、Python、python310._pth、ONNX 模型与转换脚本五项；缺项不再被旧标记误判为完整，有效模型可复用，补齐初始化无需重新下载。安装诊断持久化至 程序文件/data/logs/audio-runtime.log，保存错误分类与退出码，网址和敏感字段脱敏。版本 1.7.1 安装专项 102 项通过；该版正式目录真实首装、缺标记修复及两次短 WAV 转换均成功，输出 135／138 字节 MIDI，短样本为 1 轨 5 音符。酷狗整曲的解析成功亦不代表混音旋律准确、人工听音或游戏实机通过。查看操作与限制。

版本 1.7 的启动参数、Windows 长路径修复及独立临时目录 135 字节／5 音符转录是历史证据；版本 1.2 四格式、版本 1.3 首次安装结果也按原版本保留，不重复计入本轮。

F8 收起保留任务栏按钮，F8／F9 全局控制保留原前台；关闭主窗口取消工作、结束自己启动的后台任务，保留歌曲与账号记录。自动会话期间本窗鼠标穿透，避免演奏用鼠标修饰键点到软件并抢走前台；F5 暂停仍保持保护，F7 停止才恢复交互。前台目标保护继续生效，不据窗口保护推断游戏已接受输入。

现成 MELODY 谱优先，背景轨不再作为吹奏选项。吹奏下拉标为“主旋律”，只显示有音符的明确主旋律角色；未知 MIDI 无角色时最多提供一条明确标为不确定的旋律候选。PIANO、BRIDGE 和其他背景轨仍参与瀑布显示；没有可解释单音候选的文件拒绝载入，可能是伴奏、鼓点或复音编配，不据拒载一律判定伴奏。默认自然周期到所选主旋律末音终点，背景裁到相同周期，后端结束后播放状态回到停止；主动片段、循环、目标时长与正常长休止保留。这些规则不证明音频估计能过滤所有强伴奏尾奏，优先使用有明确 MELODY 的现成谱。查看选轨与选谱 · 查看结束规则。

节奏口琴桌面客户端采用 C# 5、.NET Framework 4.8 与 WinForms 实现，口琴功能参考公开流程、谱面表示和社区键位。双击 EXE 启动的流程不变；WebView2 SDK 约增加 0.9 MiB，复用共享网页运行时。首次音频转换才自动准备识别组件，约占 338 MiB 磁盘，此数字不是下载流量；版本 1.8.1 启动 EXE 约 1.91 MiB、低于 2 MiB。Basic Pitch 的许可与署名随组件保留，使用流程见音频转 MIDI。
